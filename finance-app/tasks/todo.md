# Q-09 — единая валюта привязок выплат к начислениям

Задача 2026-10-22 (BASA:Q-09, H5 из «карточки сотрудника»). Ветка `claude/obligation-link-currency`.
Проблема: `obligation_payments.amount` пишется в базовой валюте (LinkPaymentButton), валюте операции
(триггер 0079), валюте счёта (obligation_pay 0091), а читается как валюта начисления. Привязка из UI —
прямой insert; политика insert не проверяет команду операции; нет предела «привязки ≤ операция».

- [ ] 3. Миграция 0099 + rollback: RPC `obligation_link`, policy with check, constraint-trigger, правка 0079/obligation_pay
- [ ] 4. LinkPaymentButton (и другие прямые insert) через RPC
- [ ] 5. Ревью безопасности; npm test / tsc / build
- [ ] 6. Бэкап → репетиция на production (REHEARSAL OK, чистый откат) → «да» владельца → apply → md5 → аудит 0 FAIL
- [ ] 7. Исправление исторических строк — отдельно, после SELECT-сверки и «да» владельца
