Ты ведёшь базу знаний о сервисе Basa Finance в локальном хранилище KO:
`~/Documents/KO-Agency-Knowledge` (локальный Git, без облака). Раздел Basa —
`01_company/tech/basa_finance/`:
- `dev_rules.md` (STD-BASA-001) — правила разработки, основное место правил;
- `system.md` (ENT-BASA-001) — устройство сервиса;
- `decision_log.md` (DEC-BASA-001) — решения Дмитрия: `D-NN`;
- `current_state.md` (CUR-BASA-001) — срез состояния;
- `open_questions.md` (OQ-BASA-001) — вопросы `Q-NN`, извне `BASA:Q-NN`.
Журнал правок данных Basa помощником хранилища (EX-01) — `00_system/integrations/basa_sync_log.md`
(только читай, это не твой журнал).

## Перед любой правкой
1. Прочитай `00_system/assistant_rules.md`, `00_system/knowledge_standard.md`,
   `00_system/access_policy.md` — это правила хранилища, они главнее этого файла.
2. Найди основное место факта: `python3 00_system/tools/search.py "<запрос>"`. Второй файл на ту
   же тему не создавай.

## Как записывать
- Факт — один раз, в основном месте; в других местах — ссылка.
- Не смешивай категории: предложение / согласие / план / отчёт о выполнении / проверенный
  результат. Проверку, сделанную другим агентом, пиши как «зафиксировано в …», если сам не
  перепроверял; проверенный результат — с датой, методом и наблюдаемым итогом.
- Решения записывай только принятые Дмитрием («кто решил: Дмитрий», дата, основание);
  остальное — в «Предложения без решения».
- Неизвестное — явно; противоречия — таблицей, не разрешай по более поздней дате.
- При содержательной правке: `version` +1, `updated_at` = сегодня; у `current_state` — `content_as_of`.
- `status: active` и `owner` не ставь сам — это решает Дмитрий.
- Устаревшее не удаляй: помечай «устарело, заменено …»; файлы не удаляй (архив — `99_archive/`).
- Секреты, пароли, токены, ключи не записывай даже частично; финансовые суммы — только в
  документах с `access: finance`.

## После правки
1. `cd ~/Documents/KO-Agency-Knowledge && python3 00_system/tools/validate.py` — ошибок 0.
2. Строка в `00_system/changelog.md`: следующий `CH-SYS-NNN` после последнего в таблице,
   вставь сразу за последней строкой таблицы; «Кто» — Claude, «Основание» — задание/решение Дмитрия.
3. Если правило в `dev_rules.md` изменилось — сообщи, что нужно синхронизировать `~/Basa/CLAUDE.md`
   (рабочая копия правил для агентов).
4. Git хранилища не коммить, пока об этом не попросили.
